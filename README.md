# Nekath iOS app

Expo/React Native app using typed persistent mock APIs. Real authentication, astrology calculations, payments and AI are not connected.

```sh
yarn install
yarn ios
```

Run commands from the repository root. Yarn 4.6.0 is pinned through Corepack, with one root lockfile and the app in the `mobile` workspace.

```sh
yarn check                  # TypeScript, ESLint, tests and formatting
yarn install --immutable    # Reproducible install for CI
yarn api:examples           # Regenerate current API examples
yarn export:ios             # Export iOS JS/assets bundle
```
